# Use cases & roadmap

These are **illustrative workflows**, not customer deployments or quantified business outcomes.

## Software delivery with independent review

A coordinator creates a task with acceptance criteria. An implementation office changes a scoped branch; a QA office tests it without inheriting executor authority. Cerebro keeps decisions and evidence. Sinapsis lets a person inspect the state before publication. AMA avoids making every coordination schema direct throughout the implementation session.

**Evaluate:** conflict-free task ownership, negative tests, rollback quality, time to verified acceptance and provider-recorded cost. Do not equate more tool calls with more useful work.

## Research and durable knowledge

An office retrieves relevant sources, produces a sourced synthesis and records uncertainty. Another role checks citations and validity. Checkpoints permit a new session to continue without re-reading the entire corpus. Hybrid retrieval helps both exact identifiers and conceptual questions.

**Evaluate:** retrieval relevance, source freshness, unsupported claims and the amount of context needed to resume. Semantic similarity is not fact verification.

## Bounded operational change

The operator defines an approved reversible action. An executor checks prerequisites and expected denials, collects evidence, then submits to a proportionate gate. Production approval stays explicit; this manual is not a runbook for a real environment.

**Evaluate:** permission enforcement, attributable decisions, restore-tested backups and whether rollback stays inside scope.
