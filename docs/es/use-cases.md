# Casos de uso y roadmap

Son **flujos ilustrativos**, no despliegues de clientes ni resultados de negocio cuantificados.

## Desarrollo de software con revisión independiente

Un coordinador crea una tarea con criterios de aceptación. Una oficina implementa en una rama acotada; QA prueba sin heredar autoridad del ejecutor. Cerebro conserva decisiones y evidencia. Sinapsis permite inspeccionar estado antes de publicar. AMA evita volver directos todos los schemas de coordinación durante toda la implementación.

**Evaluar:** responsable de tarea sin conflictos, tests negativos, calidad de rollback, tiempo hasta aceptación verificada y costo registrado del proveedor. Más llamadas de tools no equivale a más trabajo útil.

## Investigación y conocimiento duradero

Una oficina recupera fuentes relevantes, produce síntesis con fuentes y registra incertidumbres. Otro rol comprueba citas y vigencia. Checkpoints permiten continuar en nueva sesión sin releer todo el corpus. Búsqueda híbrida ayuda con identificadores exactos y consultas conceptuales.

**Evaluar:** relevancia de recuperación, actualidad de fuentes, afirmaciones sin respaldo y contexto necesario para retomar. Similitud semántica no verifica hechos.

## Cambio operativo acotado

El operador define una acción reversible aprobada. Un ejecutor comprueba requisitos y denegaciones esperadas, reúne evidencia y entrega a gate proporcional. La aprobación de producción sigue explícita; este manual no es runbook de un entorno real.

**Evaluar:** cumplimiento de permisos, decisiones atribuibles, backups con restauración probada y rollback dentro de alcance.

## Roadmap de publicación: estados, no fechas

| Estado | Elemento | Criterio de salida |
| --- | --- | --- |
| Público | Seis extensiones npm y monorepo. | Conservar evidencia de compatibilidad e integridad de releases. |
| En preparación | Repo público de Cerebro. | Fuente saneada, QA de instalación y aprobación de publicación. |
| En preparación | Publicación de Sinapsis. | Fuente pública, quickstart reproducible y QA de seguridad UI/API. |
| Preparado localmente | Perfil y manual bilingüe. | QA editorial/técnica independiente y publicación del responsable. |
| Medición pendiente | Resultados representativos AMA del perfil líder. | Proceso nuevo confirmado, comparaciones mismo perfil/modelo y límites de costo registrado. |

No se prometen fechas, SLA empresarial, certificación ni metas universales de rendimiento. Consultá [estado de fuentes/publicaciones](sources.md) antes de desplegar o presentar algo previsto como disponible.
